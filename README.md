# MediVault.AI

MediVault.AI is a full-stack web application designed to securely store, manage, and share medical records digitally. The platform helps patients organize their health documents in one place while also enabling doctors and healthcare providers to access important medical information when required.

The system also integrates AI-based tools to help users analyze and summarize medical reports, making healthcare data easier to understand.

---

## Features

- Secure user authentication and account management
- Upload and store medical records safely
- AI-powered medical report summary
- Share medical records with other users through secure links
- Notifications for shared records and updates
- Document and certificate management
- Chatbot assistance for user queries
- Organized dashboard for managing all medical data

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/VookaKavyaSuma/MediVault.AI.git
cd MediVault.AI
```

### 2.Setup Backend

```bash
cd backend
npm install
npm start
```

### 3.Setup Frontend

Open a new terminal and run:

```bash
cd frontend
npm install
npm run dev
```
